MORGAN PLAYER DONATION PAGE

Files:
- index.html
- style.css
- script.js

SET YOUR DONATION LINK:
1. Open script.js.
2. Find:
   const BMC_URL = "https://www.buymeacoffee.com/YOUR_USERNAME";
3. Replace YOUR_USERNAME with your real Buy Me a Coffee username.
4. Open index.html in a browser.

You can also replace the contact email in index.html:
YOUR_EMAIL@example.com

No build tools are required. This is a standalone HTML/CSS/JavaScript page.
